# 個人學習筆記 (Personal Study Notes)

本專案為個人自主學習與實務案例練習筆記系統。

## 🚀 啟動方式（兩種皆可，完全離線本機執行）

1. **直接開啟網頁（免啟動伺服器）**  
   直接在 Finder 點兩下開啟 [`index.html`](./index.html) 即可在瀏覽器中使用所有練習、模擬考與錯題本功能。
2. **透過本機伺服器啟動**  
   點兩下執行 [`啟動練習站.command`](./啟動練習站.command)，或於終端機執行：
   ```bash
   python3 -m http.server 8700
   ```
   並開啟 `http://localhost:8700`。
